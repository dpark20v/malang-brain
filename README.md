# 말랑뇌 · 치매 예방 놀이터

집에서 혼자서도 할 수 있는 치매 예방 생활습관과 두뇌 자극 게임 사이트입니다.
병원·치매안심센터가 먼 농어촌에서도 인터넷만 있으면 쓸 수 있도록 만들었습니다.

---

## 실행 방법

가장 간단한 방법은 `index.html` 을 더블클릭하는 것입니다.

구글 로그인까지 쓰려면 서버로 띄워야 합니다:

```bash
cd ~/malang-brain && python3 -m http.server 8765
```

→ 브라우저에서 `http://localhost:8765`

---

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (홈 / 배우기 / 두뇌게임 / 말랑 스트리크 / 도움받기 / 내 기록) |
| `style.css` | 파스텔 색감, 둥근 모서리, 큰 글씨 디자인 |
| `app.js` | 페이지 이동, 게임 6종, 스트리크, 프로필 |
| `config.js` | 운영자 설정 (구글 로그인, 스트리크 목표) |

## 로그인 방식

어르신이 쓰기 쉽도록 **두 가지**를 함께 제공합니다.

### 1. 이메일 계정 (기본 · 설정 불필요)

로그인 화면에서 **이메일 → 비밀번호 → 아이디·이름** 순서로 진행합니다.

- 이메일을 넣으면 이미 가입한 계정인지 자동으로 판단합니다.
  - **처음이면** 비밀번호를 정하고, 아이디와 이름을 넣어 가입합니다.
  - **이미 있으면** 비밀번호만 넣고 바로 들어갑니다.
- 이메일이 계정 열쇠(`malang:u:e<이메일>`)라서, 나중에 서버를 붙일 때
  **그대로 서버 계정 키로 이어 쓸 수 있습니다.**
- 대소문자는 구분하지 않습니다. (`SUNJA@Gmail.com` = `sunja@gmail.com`)

#### 비밀번호 처리

비밀번호는 **절대 그대로 저장하지 않습니다.**
계정마다 다른 무작위 솔트(16바이트)를 만들고
`PBKDF2-SHA256 · 150,000회`로 해시한 값만 남깁니다.

> **꼭 알아두세요.** 서버가 없기 때문에 이 로그인은
> **"누가 쓰는지 구분하는 장치"일 뿐, 기록을 지켜 주는 보안 장치가 아닙니다.**
> 기기를 만질 수 있는 사람은 개발자 도구로 저장소를 열어 볼 수 있습니다.
> 그래서 가입 화면에 *"구글·은행 비밀번호는 넣지 마세요"* 경고를 띄웁니다.
> 진짜 보호가 필요하면 서버(Firebase Auth 등)로 인증을 옮겨야 합니다.
>
> 참고로 `crypto.subtle`이 필요해서 `http://localhost` 또는 `https://` 로
> 접속해야 로그인이 동작합니다.

### 2. 구글 로그인 (선택 · 설정 필요)

`config.js` 의 `GOOGLE_CLIENT_ID` 를 채우면 로그인 화면 아래쪽에
구글 버튼이 나타납니다. **비워 두면 버튼이 아예 보이지 않고**,
이름 프로필만으로 아무 문제 없이 동작합니다.

#### 클라이언트 ID 만드는 법

1. <https://console.cloud.google.com> 접속 → 프로젝트 만들기
2. **API 및 서비스 → OAuth 동의 화면**
   - User Type: 외부
   - 앱 이름: 말랑뇌
   - 테스트 사용자에 본인 이메일 추가
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
4. 애플리케이션 유형: **웹 애플리케이션**
5. **승인된 자바스크립트 원본**에 접속 주소를 등록
   ```
   http://localhost:8765
   https://내아이디.github.io
   ```
6. 발급된 `...apps.googleusercontent.com` 을 `config.js` 에 붙여넣기

> 구글 로그인은 `file://` 로 연 페이지에서는 동작하지 않습니다.
> 반드시 `http://localhost` 또는 실제 주소로 접속해야 합니다.

## 기록이 저장되는 곳

이 사이트에는 **서버가 없습니다.** 모든 기록은 브라우저의 localStorage,
즉 **지금 쓰는 그 기기 안에만** 저장되고 어디로도 전송되지 않습니다.

그래서 같은 계정으로 다른 휴대폰에서 들어가도 기록은 따라오지 않습니다.
기기 간 동기화가 필요하면 Firebase 같은 백엔드를 붙여야 하며,
`app.js` 의 `store` 부분만 교체하면 되도록 만들어 두었습니다.

저장 키 구조:

```
malang:pref:font        글자 크기 (기기 공통)
malang:pref:profiles    계정 목록 (이메일 · 아이디 · 이름 · 솔트 · 해시)
malang:pref:session     지금 들어와 있는 계정
malang:u:e<이메일>:log            날짜별 실천 개수
malang:u:e<이메일>:check:<날짜>   그날 체크한 항목
malang:u:e<이메일>:bestStreak     최고 연속 기록
malang:u:e<이메일>:best:<게임>    게임별 최고 기록
```
